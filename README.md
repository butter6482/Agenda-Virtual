# CoquíBook

Sistema de agenda y gestión de citas desarrollado con Next.js, Prisma y PostgreSQL.

## 🌐 Producción
https://coquibook.net

## 🚀 Tecnologías
- Next.js 15
- Prisma ORM
- PostgreSQL
- tRPC
- NextAuth

## ⚙️ Deploy
Aplicación desplegada en Render con Docker y base de datos PostgreSQL.

## 📅 Funcionalidades
- Gestión de citas
- Calendario interactivo
- Autenticación de usuarios
- Registro de tips/cuadres

## 🧑‍💻 Autor
Proyecto desarrollado por el equipo de CoquíBook.
